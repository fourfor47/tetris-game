# 游戏需求：俄罗斯方块 (Tetris)

## 游戏 ID
`tetris`

## 游戏概述
经典俄罗斯方块游戏，方块下落、旋转、消除。

## 核心玩法
1. 方块从顶部落下
2. 玩家可左右移动、旋转、加速下落
3. 一行填满后消除并得分
4. 方块堆到顶部则游戏结束
